# Online Store

Учебный проект интернет-магазина на Django.

## Описание

Проект создаётся в рамках курса по Django.  
На текущем этапе реализованы:

- базовая настройка Django-проекта;
- приложение `catalog`;
- главная страница;
- страница контактов;
- форма обратной связи;
- маршрутизация через `include`;
- HTML-шаблоны с Bootstrap.

## Технологии

- Python
- Django
- Bootstrap
- Git
- GitHub
